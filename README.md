# ReggieSoft Homebrew Tap

Official Homebrew tap for [ReggieSoft](https://github.com/reggiesoft-labs) software.

## Installation

Install ZeroG with a single command:

```bash
brew install reggiesoft-labs/tap/zerog
```

Or tap the repository first:

```bash
brew tap reggiesoft-labs/tap
brew install --cask zerog
```

## Updating

```bash
brew upgrade zerog
```

## Uninstalling

```bash
brew uninstall --zap zerog
```
